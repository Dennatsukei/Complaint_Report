# 员工名单脱敏清单

`employee_names.txt` 用于外发 LLM 请求前的员工姓名脱敏，名单不会提交到
版本库（已在 `.gitignore` 中忽略）。

## 格式

- 每个姓名占一行，支持中文姓名、中文名（含名的一部分）和英文名。
- 以 `#` 开头的行是注释。
- 文件编码建议 UTF-8（带不带 BOM 均可），也兼容 GBK。
- 姓名匹配与大小写无关；英文名只按单词边界匹配（如 `John` 不会命中
  `Johnson`）。中文全名比短名优先，例如同时列入 `王小明` 与 `小明` 时，
  `王小明先生` 会被整体处理。

示例：

```text
# 员工姓名
王小明
李娜
John Smith
```

匹配到名单中的姓名（含紧随其后的“先生/女士/小姐”）会一律替换为
“工作人员”，该替换不可逆，仅作用于发往第三方模型的请求文本。
